# ИСПУМ — Обзор безопасности и обработки данных

> Документ для отдела закупок и службы информационной безопасности образовательных
> организаций. Версия-черновик — перед передачей клиенту согласуйте с юристом.
> Последнее обновление: 2026-06.

## 1. Что такое ИСПУМ

ИСПУМ — облачный сервис для преподавателей: проверка студенческих работ с помощью ИИ
и подготовка лекционных материалов. Сервис предоставляется по модели SaaS.

## 2. Размещение данных (резидентность)

| Компонент | Размещение |
|---|---|
| Серверы приложения и база данных | Yandex Cloud, дата-центры на территории РФ |
| Файловое хранилище (загруженные документы) | Yandex Object Storage, РФ |
| Резервные копии | Yandex Cloud, РФ |

Персональные данные граждан РФ хранятся в базах данных на территории Российской
Федерации в соответствии с ч. 5 ст. 18 Федерального закона № 152-ФЗ.

## 3. Какие данные обрабатываются

- **Данные преподавателя:** имя, адрес эл. почты, организация, телефон (необязательно).
- **Данные студентов:** имя и адрес эл. почты (**необязательные** поля), текст
  присланной работы. Сервис не требует ввода персональных данных студентов —
  работу можно проверять анонимно.
- **Служебные данные:** журналы использования, метаданные платежей.

## 4. Меры защиты

- **Шифрование канала:** весь трафик по HTTPS (TLS 1.2/1.3). HTTP перенаправляется на HTTPS.
- **Пароли:** хранятся в виде хэшей bcrypt (cost 12), в открытом виде не хранятся и не передаются.
- **Аутентификация:** JWT (HS256), срок жизни токена 7 дней; смена пароля инвалидирует ранее выданные токены.
- **Разграничение доступа:** ролевая модель (преподаватель / администратор организации /
  администратор платформы). Данные одной организации недоступны другой.
- **Защита API:** заголовки безопасности (helmet), ограничение частоты запросов
  (rate limiting), валидация всех входных данных, параметризованные SQL-запросы
  (защита от инъекций), фильтрация попыток prompt-инъекций в пользовательском тексте.
- **Изоляция:** приложение работает под отдельным системным пользователем, не от root.

## 5. Привлекаемые третьи лица (субобработчики)

| Субобработчик | Назначение | Размещение | Трансгранично |
|---|---|---|---|
| Yandex Cloud | Хостинг, БД, хранилище | РФ | Нет |
| Unisender Go | Отправка транзакционных писем | РФ | Нет |
| DeepSeek | Обработка текста ИИ (проверка, генерация) | вне РФ | **Да** |

> ⚠️ **Важно про ИИ-обработку.** Текст работы для проверки и параметры лекции
> передаются провайдеру модели ИИ (DeepSeek) для обработки. Это трансграничная
> передача. Рекомендуется: не указывать персональные данные студентов в полях
> «Имя/Email» (они необязательны) и не включать в текст работ избыточные
> персональные данные. По запросу для институциональных клиентов возможен переход
> на модель, размещённую в РФ (см. раздел «Дорожная карта»).

## 6. Права субъектов и удаление данных

- Преподаватель может удалить свой аккаунт и все связанные данные (каскадное удаление
  по всем таблицам) — самостоятельно в разделе «Настройки».
- По запросу организации данные её преподавателей могут быть выгружены или удалены.

## 7. Доступность и непрерывность

- Мониторинг доступности и оповещения.
- Резервное копирование базы данных.
- Эндпоинт проверки состояния: `GET /api/health`.

## 8. Дорожная карта по безопасности (для институциональных клиентов)

- Соглашение об обработке ПДн (DPA) — по запросу.
- Опция обработки ИИ на модели, размещённой в РФ (YandexGPT), — для исключения
  трансграничной передачи.
- Журнал действий администратора (аудит).
- Экспорт отчётов и данных.
