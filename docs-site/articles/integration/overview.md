ИСПУМ — облачный сервис (SaaS): преподаватели работают в браузере, установка
на компьютеры не требуется. Для ИТ-службы университета интеграция сводится к
трём областям.

## Вход преподавателей

ИСПУМ поддерживает вход по логину/паролю "из коробки" и, отдельно, единый
вход через SSO (SAML) для университетов, у которых уже есть свой провайдер
идентификации (например, на базе Active Directory). Настройка SSO описана в
разделе «Настройка входа по SAML» этого раздела.

## Работа из LMS

Если университет использует Moodle (или другую LMS с поддержкой LTI 1.3),
ИСПУМ можно подключить как внешний инструмент — задания, публикуемые в
ИСПУМ, появляются прямо в курсе LMS, а состав группы синхронизируется
автоматически. Подробности — в статье «Настройка LTI 1.3».

## Роли и доступ

Доступ внутри ИСПУМ строится на оргструктуре университета (институты →
кафедры), а не на плоском списке ролей: администратор может выдать право
редактирования конкретному подразделению, не открывая доступ ко всему
университету. Приглашение и деактивация преподавателей централизованно
закреплены за ИТ-службой и не делегируются на уровень кафедры — это
сознательное решение, а не ограничение текущей версии.
