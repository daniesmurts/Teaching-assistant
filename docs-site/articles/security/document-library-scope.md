По умолчанию загруженные преподавателем материалы (программа курса,
методички, конспекты) используются платформой только в контексте того
предмета, к которому они прикреплены. Преподаватель может по желанию
расширить область видимости материала — это описано ниже.

## Область видимости

Материал может быть на одном из четырёх уровней:

- **Предмет** (по умолчанию) — виден только при генерации контента для
  этого же предмета.
- **Кафедра** — виден при генерации для любого предмета того же
  подразделения (по орг-структуре учебного заведения).
- **Учебное заведение** — виден при генерации для любого предмета в
  рамках всего заведения. Доступно только на тарифе «Институция».
- **Платформа** — куратируемый ИСПУМ контент; недоступен через
  пользовательские действия, только через прямую публикацию.

Материал своего предмета никогда не вытесняется материалом более
широкой области — платформа сначала использует то, что преподаватель
загрузил сам, и только затем дополняет пул из кафедры/заведения.

## Кто разрешает расширение области

Расширение видимости не проходит через отдельную модерацию — оно
использует те же права доступа, что и остальные функции УМУ:

- до уровня **кафедры** — сам преподаватель (по умолчанию — в своё
  собственное подразделение) или любой сотрудник с правом
  редактирования в домене УМУ на целевое подразделение;
- до уровня **учебного заведения** — только сотрудник с правом
  редактирования УМУ на корневой единице организационной структуры
  (фактически — институциональный администратор УМУ), и только на
  тарифе «Институция».

## Происхождение материала

При расширении видимости преподаватель обязан указать происхождение:
собственная разработка, открытая лицензия, собственность заведения, или
«не уточнено». Это описательная отметка — платформа не проверяет
авторские права автоматически. Материал с отметкой «не уточнено» может
быть расшарен только в рамках заведения, но не публикуется на уровне
платформы.

## Что видит другой преподаватель

Расширение видимости не передаёт файл целиком — материал остаётся в
хранилище исходного преподавателя. Другой преподаватель получает только
то, что уже получает при обычной генерации контента: релевантные
фрагменты текста (с указанием источника) и, если материал содержит
чертежи или сканы (встроенные изображения в .docx или отдельные страницы
PDF, распознанные как содержащие немного текста) — найденные изображения,
показанные при подборе иллюстраций для презентации.

## Учёт использования

Каждое использование материала за пределами исходного предмета
фиксируется (без содержимого — только факт и предмет-получатель) и
видно как автору материала (счётчик использований), так и
администратору УМУ на странице «Библиотека кафедры».
